# शिव स्वरोदय ज्ञानकोष

शिव स्वरोदय की पारंपरिक मान्यताओं को आधुनिक, उत्तरदायी और शैक्षिक रूप में प्रस्तुत करने वाला responsive Hindi portal।

## विशेषताएँ

- स्वर पहचान उपकरण और स्थानीय अवलोकन
- इड़ा, पिंगला, सुषुम्ना तथा दस नाड़ियों का परिचय
- दस प्राण और पंचतत्त्व
- सरल शैक्षिक होरा कैलकुलेटर व 24-घंटे की समयरेखा
- localStorage आधारित दैनिक स्वर डायरी और सात-दिन सारांश
- अभ्यास स्तर, सुरक्षा सूचना और चिकित्सकीय अस्वीकरण

## स्थानीय विकास

```bash
npm install
npm run dev
```

गुणवत्ता जाँच: `npm run lint` और `npm run build`।

> यह परियोजना केवल शैक्षिक उपयोग के लिए है। यह चिकित्सा-जाँच, निदान या उपचार का विकल्प नहीं है।
